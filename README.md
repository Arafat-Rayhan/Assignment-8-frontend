A Journey Towards Guidance, Goodness & A Better Society
দ্বীনের পথে আহ্বান, গুনাহ থেকে প্রত্যাবর্তন এবং একটি সুন্দর সমাজ গঠনের সম্মিলিত প্রয়াস।

🌿 About The Project
Dawat to Din একটি ইসলামিক কমিউনিটিভিত্তিক ওয়েব অ্যাপ্লিকেশন। এর মূল উদ্দেশ্য হলো মানুষকে আল্লাহর পথে আহ্বান করা, ইসলামের সৌন্দর্য ছড়িয়ে দেওয়া এবং সমাজের নৈতিক ও সামাজিক অবক্ষয় রোধে ইতিবাচক ভূমিকা রাখা।

বর্তমান সময়ে বিশেষ করে যুবসমাজ বিভিন্ন ধরনের অনৈতিকতা, মাদকাসক্তি, অশ্লীলতা এবং সামাজিক অবক্ষয়ের ঝুঁকিতে রয়েছে। একইভাবে সমাজের বিভিন্ন স্তরের মানুষ সঠিক দিকনির্দেশনার অভাবে বিপথে পরিচালিত হচ্ছে।

আমাদের বিশ্বাস, একটি সুন্দর সমাজ গঠনের জন্য প্রয়োজন সঠিক জ্ঞান, উত্তম চরিত্র, পারস্পরিক সহযোগিতা এবং আল্লাহর প্রতি ভালোবাসা।

Dawat to Din সেই লক্ষ্যেই একটি প্ল্যাটফর্ম, যেখানে মানুষ ইসলামিক ও সামাজিক সচেতনতামূলক কার্যক্রম তৈরি করতে, নিজেদের মধ্যে সংযুক্ত হতে এবং ভালো কাজের উদ্যোগে অংশগ্রহণ করতে পারবে।

"তোমাদের মধ্যে এমন একটি দল থাকা উচিত, যারা কল্যাণের দিকে আহ্বান করবে, সৎকাজের নির্দেশ দেবে এবং অসৎকাজ থেকে নিষেধ করবে।"

— সূরা আলে ইমরান, ৩:১০৪

🎯 Our Mission & Vision
আমাদের লক্ষ্য কেবল একটি ওয়েবসাইট তৈরি করা নয়; বরং প্রযুক্তির মাধ্যমে একটি ইতিবাচক পরিবর্তনের সূচনা করা।

🕌 মানুষকে আল্লাহর পথে আহ্বান করা।

🌍 সামাজিক অবক্ষয় প্রতিরোধে সচেতনতামূলক উদ্যোগ তৈরি করা।
📖 দ্বীনি জ্ঞান, ভালো চিন্তা ও ইতিবাচক বার্তা ছড়িয়ে দেওয়া।
🌸 নারী-পুরুষ নির্বিশেষে সবাইকে সম্মানজনক ও কল্যাণকর সমাজ গঠনে উৎসাহিত করা।

⚙️ Installation & Setup
Follow these steps to run the project locally.

1. Clone the Repository
git clone YOUR_REPOSITORY_URL
2. Navigate to Frontend
cd frontend
3. Install Frontend Dependencies
npm install
4. Configure Environment Variables
Create a .env.local file in the frontend directory.

Add the environment variables required by your frontend configuration.

5. Start Frontend Development Server
npm run dev
Frontend will run at:

http://localhost:3000
6. Setup Backend
Open another terminal:

cd backend
npm install
Configure your backend environment variables, including database and authentication credentials.

Then start the backend using the development script configured in your package.json.

🔒 Environment Variables
The project requires environment variables for API configuration, authentication, database connectivity and image management.

Frontend .env.local

NEXT_PUBLIC_CREAT_POST=
NEXT_PUBLIC_POSTS_URL=
Backend .env

PORT=
DB_URI=
Add other authentication and Cloudinary credentials according to your backend configuration.

Important: Never commit .env files, API secrets, database credentials or private keys to GitHub.

💡 Our Philosophy
আমরা বিশ্বাস করি, পরিবর্তন শুরু হয় একজন মানুষ থেকেই।

একজন মানুষ যখন নিজেকে সংশোধন করে, তখন তার পরিবারে পরিবর্তন আসে। পরিবার পরিবর্তিত হলে সমাজেও ইতিবাচক প্রভাব পড়ে।

আমরা চাই, প্রযুক্তি শুধু বিনোদনের মাধ্যম হয়ে না থাকুক; বরং এটি হোক কল্যাণ, সচেতনতা এবং মানবিক মূল্যবোধ ছড়িয়ে দেওয়ার একটি মাধ্যম।
